Python-Free Orchestration

Axi compiles directly to C and machine code. Connect to tensor backends like llama.cpp natively via FFI without the overhead or dependency hell of Python.

The TOON DAG Ledger

Forget Git. Axi ships with a built-in Directed Acyclic Graph (DAG) version control system, serialized in TOON—a highly compressed format designed for LLM context windows.

Zero-GC Performance

Absolute deterministic memory control. Axi is engineered from the ground up to support bare-metal hardware acceleration and AVX-512 tensor math pipelines.

Native AI, Built Beautifully

Execute model quantization and hardware orchestration natively.

import core::dag;
import ffi::llama_cpp;

pub fn main(args: string[]) {
    // 1. Hook directly into the C++ backend
    let quantize_params = llama_cpp::llama_model_quantize_default_params();
    quantize_params.ftype = llama_cpp::LLAMA_FTYPE_MOSTLY_Q4_K_M;

    // 2. Quantize the model
    llama_cpp::llama_model_quantize("model.bin", "model.gguf", quantize_params);
    
    // 3. Commit the metadata directly to your TOON DAG
    dag::commit("model_registry", "{\n  \"format\": \"GGUF_Q4\"\n}", []);
}
