# Security Policy

## Supported Versions

Currently, Axi is in a Beta testing phase. Security updates are applied directly to the main branch.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Axi very seriously. If you discover a security vulnerability, we ask that you report it to us immediately, and please give us the time to respond before making the vulnerability public.

**Please DO NOT report security vulnerabilities via public GitHub issues.**

Instead, please report them to our security team via email at:
security@the-ethos-project.com

We will attempt to respond to your report within 48 hours. If the vulnerability is accepted, we will work out a timeline for a patch and coordinate a disclosure.
