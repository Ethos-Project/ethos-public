# Contributing to Axi

First off, thank you for considering contributing to Axi! It's people like you that make Axi a great language.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our **Issues** tab to see if someone else has already created a ticket. If not, go ahead and make one!

## 2. Fork & pull request workflow

1. **Fork** the repo on GitHub.
2. **Clone** the project to your own machine.
3. **Commit** changes to your own branch.
4. **Push** your work back up to your fork.
5. Submit a **Pull Request** so that we can review your changes.

**Note:** Be sure to merge the latest from "upstream" before making a pull request!

## 3. Local Development

To compile Axi locally from source, you will need CMake and a compatible C/C++ build toolchain. 

1. Ensure CMake is installed.
2. Run the build scripts provided in the root directory (e.g. uild_ide.ps1 for Windows users).
3. Ensure all tests pass before submitting a PR.

## 4. Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. We expect a welcoming, inclusive, and harassment-free environment for everyone.
